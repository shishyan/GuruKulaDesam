Guru Kula Desam — Privacy Policy

YouTube API Compliant

Last Updated: October 2026 | Official Portal: https://gurukuladesam.com

YouTube API Services Notice: Guru Kula Desam uses YouTube API Services to manage channel captions, video descriptions, and digital cultural archive publication. By using or interacting with our services, you agree to be bound by the YouTube Terms of Service and the Google Privacy Policy.

1. Overview & Purpose

Guru Kula Desam is a digital sanctuary and educational repository dedicated to classical Tamil scriptures, devotional hymns, and cultural heritage. The Guru Kula Desam Channel Synchronizer tool is used to upload authentic scripture lyrics into YouTube video descriptions and publish synchronized .srt closed-caption tracks for hearing accessibility and linguistic study.

2. Google & YouTube API Services

Our applications utilize the official YouTube Data API v3 provided by Google LLC:

  • We adhere strictly to the YouTube API Services Terms of Service and YouTube Developer Policies.
  • Please refer to Google's primary privacy statement here: http://www.google.com/policies/privacy.

3. Data Accessed, Collected, and Stored

Our tool operates strictly as an internal channel owner utility with OAuth 2.0 authorization:

  • Channel Content: We read video IDs, titles, descriptions, and existing caption tracks for videos owned by the Guru Kula Desam YouTube channel.
  • No Personal User Data: We do NOT collect, harvest, sell, or profile any viewer personal information, viewer comments, search histories, or viewing habits.
  • OAuth Tokens: Authorization tokens are stored encrypted and locally on authorized operator hardware strictly to execute batch caption and description synchronization tasks.

4. Data Retention, Sharing, and Deletion Policy

  • No Third-Party Sharing: No data obtained through the YouTube API is shared, transferred, leased, or disclosed to any external third parties or advertisers.
  • Data Retention: API response cache files and synchronization status manifests are retained locally only as long as necessary to prevent redundant API calls and respect YouTube quota limits.
  • User Data Deletion: Channel owners and users may delete stored OAuth tokens, sync manifests, and cache files at any time by removing the local credentials directory or by contacting privacy@gurukuladesam.com. All local cached metadata will be permanently purged within 24 hours of request.

5. How to Revoke Access

Users and channel administrators who have authorized the Guru Kula Desam Channel Synchronizer may revoke access at any time via the official Google Security Settings page:

Revoke Access via Google Security Settings (https://security.google.com/settings/security/permissions)
